# 对话 05：纯文字汇总改为整张图滑入与超大字号极简排版

## 用户原话

> 不需要逐段播放，直接用一整张图片移动进画面中。
>
> 具体要求如下：
> 1. 画面简洁：不要太多颜色，也不用太多小序号之类的元素，简单一点。
> 2. 字体放大：字体一定要放大，放大到 5 PS 都行，反正要方便阅读。

---

## 思考过程与设计判断

1. **整图缓存滑入（Single-Sheet Slide-In）**：
   - 取消逐板块、逐行分时动画，改为使用 `WeakMap<TextSummaryBoardData, HTMLCanvasElement>` 离屏预渲染整张 `1080 × 1920` 纯黑汇总图。
   - 进场时仅做整张画面的平滑上移滑入与淡入，播放过程画面零闪烁、零多余动态干扰，极度利于观看和暂停截屏。
2. **克制色彩与极简排版**：
   - 去掉所有花哨的多色点缀和小序号角标；仅保留 `#000000` 纯黑底、板块标题及重点标签的克制暖金（`#FACC15` / `#FDE047`）以及高对比纯白正文（`#FFFFFF`）。
   - 加入动态自适应测算（`measureSingleSheetLayout`），在不溢出画面边界的前提下尽可能向上顶格放大正文与标题字号。

## 对应执行动作

- 重构 `src/video/engine/scenes/TextSummaryBoardScene.ts`，实现离屏整图预渲染缓存、整张滑入动画、去编号去杂色极简视觉，以及自动字号最大化布局算法。
