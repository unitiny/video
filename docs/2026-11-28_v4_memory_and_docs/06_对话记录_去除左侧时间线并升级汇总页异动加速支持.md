# 对话 06：盘前一览去除左侧时间线竖线、进一步放大汇总页并支持宏观异动强调

## 思考过程与设计判断

1. **盘前一览极简去边条**：
   - 删除 `MarketChronoBoardScene.ts` 中最左侧贯穿全高的时间线细线与节点圆点。
   - 在 `primitives.ts` 的 `polished` 深色玻璃模式下，同步隐藏卡片左侧突兀的 `6px / 8px` 彩色竖块，让左边界干净利落、无碎块感。
2. **汇总页吃满下方可用空间**：
   - 将安全底边向下延展至 `y = 1808`（保留合理抖音底部呼吸边距），把自适应正文字号上限放宽到 **`39px`**、行距提升至 **`1.46×`**, 将剩余纵向余量智能均匀分配给条间距（`bonusPerItem`）与板块间距（`bonusPerSec`），彻底解决拥挤感。
3. **宏观异动检测与视觉强调（`highlightAnomalies`）**：
   - 支持按 `anomalyThresholdPct`（默认 `±2.5%`）正则扫描宏观行内的涨跌幅数值；若日内出现超阈值剧烈异动，自动切换为加粗超大高亮红/绿色强调；本次实盘均在平稳区间内，故保持正常中性展示。

## 对应执行动作

- 升级 `src/video/engine/scenes/TextSummaryBoardScene.ts` 与 `schema.ts`，放大字号行距并接入 `highlightAnomalies` 异动加速强调逻辑；在 `episode.json` 中为宏观行配置该字段。
