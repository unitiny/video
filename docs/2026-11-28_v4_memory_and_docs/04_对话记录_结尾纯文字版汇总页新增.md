> AI算力：

> 以上风格做一个汇总，一个页面（一张图）显示完，而且是纯文字版。重点是文字要清晰，要让人看得清楚，方便用户阅读。你可以去掉【】
> 里边的风格、动画什么的，你自己看着加，怎么方便用户观看怎么来，怎么吸引用户看怎么来

## 思考过程与设计判断

1. **纯黑一图流复盘收官架构**：
   - 将原工程化的双情景收官或长尾切换升级为更适合读者截图收藏的 **纯黑底纯文字汇总场景**（`kind: "text_summary_board"`），直接落地对应 `2026-11-26-v4` 当日真实盘面与四大主线内容（宏观 / AI算力 / 商业航天 / 机器人）。
   - 遵循用户要求去掉 `【】` 括号，以简洁的高对比度文字排版呈现，确保一屏展示完所有核心要点。
2. **Schema 与全链路集成**：
   - 在引擎 Schema 中定义 `TextSummaryBoardScene`，同步接入场景注册表、音频节拍合成器（开屏轻扫与落字清脆和弦）、剧集质检脚本及单元测试。

## 对应执行动作

- 新增 `src/video/engine/scenes/TextSummaryBoardScene.ts`，并在 `src/video/engine/schema.ts`、`src/video/engine/scenes/index.ts`、`src/video/engine/audioSynth.ts`、`scripts/validate-episode.ts`、`src/video/engine/engine.test.ts` 完成全链路注册与测试。
- 在 `episodes/2026-11-26-v4/episode.json` 末尾追加第 6 幕 `v4-06-text-summary`（`210 帧` / 7.00s，全片总计 `1428 帧` / 47.60s）。
