# 对话 02：盘前一览去缩略日 K、放大涨跌幅并新增三连指路动态箭头

## 用户原话

> 盘前伊朗的指数，删除每个指数下左侧缩略的日 K 图，然后内容要替换为指数的涨跌幅，具体修改要求如下：
>
> 1. 位置与样式：将现在右上角的指数涨跌幅移到日 K 图的位置，字体要放大，使指数显示得更醒目。
> 2. 背景动画箭头：数字背景需要添加一个箭头动画效果。
>    (a) 颜色与方向：如果是跌，生成一个绿色的向下箭头；如果是涨，生成一个红色的向上箭头（像指路一样向上延伸）。
>    (b) 视觉要求：箭头要作为数字的背景铺垫，不能太显眼。
>    (c) 形状与风格：只要箭头顶端那 3 个箭头向上延伸的效果。可以找找你很早之前的视频风格，或者你自己再生成一个就好。
> 3. 布局保持：右侧依然保持现在的分时图。目前下方介绍的字体字号还需要增大一点

---

## 思考过程与设计判断

1. **指数卡片视觉减法与焦点重塑**：
   - 原卡片右上角放涨跌幅、左侧放 5 日缩略日 K、右侧放分时，信息密度高且涨跌幅不够醒目。
   - 改为：**顶部仅保留居中左对齐的大号指数名称**；**左半格改为大字号涨跌幅方格（`drawChangePctHeroBox`）**；**右半格完整保留 48 点全天分时图（`drawMiniIntradayChart`）**。
2. **三连指路箭头（红涨绿跌）**：
   - 遵循 A 股视觉习惯：**涨（`>= 0`）用红色向上三连箭头，跌（`< 0`）用绿色向下三连箭头**。
   - 仅绘制 3 个堆叠的箭头顶端（Chevron，无竖向箭杆），作为数字后方的低对比铺底，避免喧宾夺主。
3. **下方解读文字放大**：
   - 放大美股、亚太、大宗商品与 A50 下方解析 Strips 的标题与正文字号，提升移动端竖屏可读性。
