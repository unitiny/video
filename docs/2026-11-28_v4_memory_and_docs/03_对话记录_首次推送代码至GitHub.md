## 思考过程与安全规范

1. **仓库历史对齐**：
   - 目标公开仓库为 `https://github.com/unitiny/video.git`（默认分支 `main`）。
   - 严格遵循 `.gitignore`（排除 `node_modules/`、`dist/`、`.env*`、`episodes/_previews/` 等），确保本地体积轻量化与敏感凭据隔离。
2. **凭据安全隔离（铁律）**：
   - 推送时仅在临时命令参数中使用认证凭据，推送完成后立即清理 `.git/config` 中的含密钥远程地址及任何临时凭据，绝不将 Token 明文写入代码、提交日志或仓库文档。
