# 对话 08：箭头柔化放慢与“主流大宗波幅收敛”2×2 大卡片重排及自检验收

## 用户原话

> 现在这个上下箭头又过于显眼了，稍微暗一点，速度放慢一点。
>
> 在“主流大宗波动收敛”板块，我发现有 4 个商品的涨跌幅数字和名称太小了。
>
> 重新排版一下，看看怎么让字体变大、涨跌幅也明显一点，这样更容易看嘛。重新设计后自己验收一下。

---

## 思考过程与设计判断

1. **上下箭头亮度与流速精调**：
   - 将填充与描边峰值透明度由 `0.36 / 0.62` 下调至 **`0.15 / 0.25`**，环境渐隐波与竖向速度线同步减淡；
   - 将传送带与速度线的推进速度减半（`cycleSpeed` 由 `0.024 / 0.028` 降至 **`0.010 / 0.012`**），呈现沉稳、高级、不干扰读数的背景质感。
2. **大宗商品板块由“一排 4 窄格”重排为“2×2 大横向卡片”**：
   - 原先 `1008px` 宽度内横排 4 个卡片，每个仅 `232px` 宽，商品名称只得 `23px`、数字 `30px` 且容易横向挤压。
   - 利用调整纵向布局腾出的高度（大宗区域增高至 `362px`：`y = 942..1304`），重排为 **2 行 × 2 列大横向卡片（每卡 `474 × 86 px`）**：
     - 左侧配红/绿方向色条 + **`33px` 加粗白色商品名称**（宽裕不压缩）；
     - 右侧配红/绿半透明高亮徽章盒（`168 × 56 px`）+ **`40px` 粗体等宽涨跌幅百分比**；
     - 底部保留 **`35px` 字号 / `50px` 行高**的 2 行平稳过滤解析。
3. **自行模拟坐标与换行验收**：
   - 通过脚手架对第 2 幕渲染上下文进行像素坐标与文本折行实测：确认 4 个大宗商品名称与 `%` 徽章间距充裕无挤压，美股/亚太/大宗/A50 全板块上下零重叠、无残余打字机光标、底部留白 `134px` 安全达标。
