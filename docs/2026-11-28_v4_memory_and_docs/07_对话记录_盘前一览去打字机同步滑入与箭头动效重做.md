# 对话 07：盘前一览去打字机同步滑入、放大排版并重做流动箭头背景

## 用户原话

> 1. 文本呈现方式：“盘前一览”那种分析文字不需要逐个字打出来，跟着指数一起弹出来就行，移动进入视野即可。逐个字打有点慢，别浪费时间。
> 2. 排版样式：分析文字的字体要变大一点，行距也要变大一点。现在太拥挤了，不方便阅读。
> 3. 动画动效：上下箭头的动画效果还是没有出来。你自己思考一下怎么生成一个动画镜头的动效背景，作为跌幅数据下方的打底背景，要显眼一点，并且是一直在动的动画。

---

## 思考过程与设计判断

1. **为什么之前的三连箭头看起来像没动**：
   - 此前 `drawChangePctHeroBox` 仅做了 `±5~9px` 原地正弦微摆且透明度低至 `0.08~0.21`，在黑底与视频压缩后几乎不可辨识。
2. **重做“持续流动推进的动画镜头背景”**：
   - 改为 **3 层宽幅三连箭头传送带无限循环推进**：正向（红）由底向顶连续推升、负向（绿）由顶向底连续下行，配合竖向流光速度线与边缘平滑淡入淡出，整段镜头播放期间持续运动。
   - 在百分比数字后方追加厚深色描边轮廓（`strokeText`），确保流动背景显眼的同时数字依然绝对清晰。
3. **全面取消打字机、同步滑入与放大行距**：
   - 为 `drawTypewriterSummaryStrip` 与 `drawCleanIndexCard` 增加 `instantReveal` / `heroInstantReveal` 模式，去掉 `sliceTypewriterText` 与 `▌` 光标；`drawCompactPolishedCommodityCard` 同步改用整段随卡片滑入。
   - 同步静默 `audioSynth.ts` 在 `safeInset` 盘前一览中的打字机滴答音效。
   - 调整纵轴空间：美股/亚太解析卡放大至 `40px` 标题 + `35px` 正文 + `50px` 行距；大宗解析同步提升至 `35px / 50px`；A50 底部注释提升至 `39px / 53px`。
