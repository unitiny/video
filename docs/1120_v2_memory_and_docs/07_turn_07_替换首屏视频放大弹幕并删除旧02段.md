## 思考过程与设计判断

1. **首屏弹幕升级**：观众喜欢信息弹幕横向掠过的节奏感，但觉得先前字太小、数量偏少。决定在 Shot 01 中将弹幕升级为覆盖「今日决战梗 + 美股重挫 + 商品流动性挤兑 + 日韩同步下跌 + A50 盘前走势」的 5 道行情核心摘要，并大幅提高字号与对比描边。
2. **指数看板字号升级**：手机竖屏下若卡片标题和跌幅低于 30px，肉眼阅读费力，决定全面提大卡片标题、涨跌幅百分比及下方总结文字的字号。
3. **关于删除旧 02 段的排查线索**：用户当时粘贴列表时带出了 `02 120–509 帧`，但实际真实意图是删除重复的「大字版全球指数动态竞赛 × 金油冰火天平」，这在第 08 轮得到用户明确澄清。
