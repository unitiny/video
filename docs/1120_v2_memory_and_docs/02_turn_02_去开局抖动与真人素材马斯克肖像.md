# 对话 02：去除开盘震动、引入「今天很关键」真人素材与马斯克真人头像参照

## 用户原话（第 02 轮）

> 1. 开盘不需要这么震动，开局去掉抖动，不要抖。
> 2. 找一些真人的素材（不要 AI 生成的），做一个关于“今天很关键”这个梗的有梗、有吸引力的动画。
> 3. 比如马斯克，你应该用真人的头像去生成图像才行啊。

---

## 思考过程与设计判断

1. **去全局震动（Shake Removal）**：整屏高频晃动虽然制造紧张感，但在手机竖屏观看时容易造成视觉疲劳与眩晕，文字边缘发虚。开局改为**零全屏抖动**，改用镜头平滑微推进、局部弹跳与冲击波来维持张力。
2. **「今天很关键」梗的真人实拍策略**：不能再用 AI 合成「伪真人」来凑，必须使用互联网公开版权的真实人物实拍动作视频/图片素材，确保微表情、皮肤质感、手势反应自然真实、有梗有代入感。
3. **人物肖像参照约束**：第 05 段「马斯克与机器人洗碗/家务时间轴」若脱离真人特征会失去辨识度；需先检索确认马斯克真实头像作为图像参照源，再生成厨房同框视觉资产（`eventMuskRealKitchen`）。

## 对应执行动作

- 移除 Shot 01 的全画布 `translate` 相机抖动逻辑，保持坐标系稳定。
- 检索并接入真实实拍反应素材与马斯克真实肖像参考图，将生成的真实系肖像厨房同框图绑定至 `INTEL_V2_ASSETS.eventMuskRealKitchen`。
