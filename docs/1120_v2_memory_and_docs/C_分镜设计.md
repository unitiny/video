## 各镜空间分区与细节设计

### 镜 01：极速吸睛开屏（`0–77 帧`，`0.0s–2.6s`）
- **视觉分区（Y 轴）**：
  - `y = 46`：5px 极简顶部进度条（无碎字、无红点角标）
  - `y = 128`：上方 1 条开篇定位弹幕（`52px`，贴近顶部暗化天空蒙版，不遮眼眉）
  - `y = 190 – 720`：**人脸通话黄金禁遮区**（完整呈现紧迫通话神情）
  - `y = 806 / 892 / 978`：西装胸前暗色区 3 条核心行情弹幕（`52px`，零背景混色、对比度极高）
  - `y = 1030 – 1280`：**抬腕看表核心动作区**（完整留白呈现手表时间动作，零文字遮挡）
  - `y = 1380 – 1680`：立体波普主视觉（`● 今日盘前第一信号` + `今天` `[很]` `关键!!` + 16 束旋转放射线 + 双层扩散冲击环）
  - `y = 1802`：底部第 5 道 A50 锚定弹幕（`54px`）
- **动力学参数**：
  - 弹幕 10 帧 `easeOutCubic` 甩入读屏安全区 `[48..1012]`；主标题 `f=3..16` `easeOutBack` 砸落；`f=14` 起双轮白金扫光；`f=64..74` 对称光刃合拢清屏。

### 镜 02：时序拆解全球实盘日 K 与全天分时（`78–497 帧`，`2.6s–16.6s`）
- **布局矩阵（`x = 56..1024`，双列卡宽 `476px` / 底部通栏 `968px`）**：
  - `Tier 1 (y ≈ 158)`：`纳斯达克 IXIC` ｜ `费城半导体 SOX` + 高亮打字机区（`隔夜纳斯达克与费半集体重挫` + 消息面归因，停留 1.0s）
  - `Tier 2 (y ≈ 560)`：`韩国 KOSPI` ｜ `日经 225` + 打字机区（`亚太科技权重同步低开单边下探`）
  - `Tier 3 (y ≈ 952)`：`COMEX 黄金 GOLD` ｜ `纽约天然气 NG` + 打字机区（`大宗商品显著异动（WTI原油平盘已过滤）`）
  - `Tier 4 (y ≈ 1344)`：`富时中国 A50` 通栏金边特写卡 + 分时状态打字机（`早盘急探 -2.30% 触底，随后窄幅震荡回升企稳`）
- **防失真规范**：左区固定绘制 5 根真实 OHLC 日 K 线（`Math.max(0.01, maxV - minV)` 自适应量程），右区随分时进度实时同步绘制 48 点曲线、黄线均价线与 P95 规范化成交量柱。

### 镜 03：Vox 剪纸流动性抽血漏斗（`498–647 帧`，`16.6s–21.6s`）
- **视觉切换**：从深黑终端瞬间切入暖白网格纸面风格（视觉反差唤醒注意力），3 路资产流向经无交叉三次贝塞尔曲线汇聚于中央吸金漏斗，叠加 68 家跌停背景数据与防守型观察窗口标尺。

### 镜 04：Focus-and-Dim 双焦聚光对比（`648–797 帧`，`21.6s–26.6s`）
- **景深控制**：前半段左栏全亮展示「2028 年中 PCB 硬短缺预警」，右侧压暗；过半切为右栏聚光，「未量产 · 需审慎」红色物理印章自高空砸落（触发音频撞击），底栏给出「紧缺逻辑可关注，科技承压忌追高」的理性总结。

### 镜 05：真人肖像厨房与机器人时间轴（`798–947 帧`，`26.6s–31.6s`）
- **去框化融合构图**：顶部嵌入基于真实马斯克头像绘制的厨房同框画面，下方取消重框体束缚，改用渐变悬浮时间胶囊横向展开 `1–2月 -> 11.25 -> 12–18月` 产业催化节点，底部以警示横幅提示「缩量博弈高开一致易分歧」。

### 镜 06：客观规律总览 × 10:00 分化双情景推演（`948–1187 帧`，`31.6s–39.6s`）
- **双区终局构图**：
