# Turn 13 — 更换首屏非感叹真人看表实拍并维持 2.6 秒极速开屏

## 用户原话
> 首屏动画换一个，不要现在的人物感叹的。同样要保持首屏时长压缩至 2.6 秒

## 分析与决策思考
1. **去除「人物感叹」气质，转向紧迫决战氛围**：原 Mixkit `4508`（睁眼张嘴双手抱头）偏向情绪化感叹；本次从 Mixkit 检索并对比多个商务/交易实拍片段，最终选定 `45749`（穿深色西装的商务人士边接听紧急电话边利落抬腕看表），既贴合「今天很关键 / 08:00 盘前节点」的紧迫感，又无夸张感叹表情。
2. **竖屏精准裁切与高潮时间窗提取**：
   - 下载 `720p` 高清源 `real_keyday_watch_45749.mp4` 并提取专属封面 `real_keyday_watch_poster.jpg`，删除旧 `4508` 资产，同时将 `renderV2KeyDayVideoScene` 的未就绪回退目标也由惊愕照改为 `realKeyDayPoster`，杜绝首帧闪现感叹表情。
   - 在 `INTEL_V2_VIDEO_SAMPLE` 中设定 `minSec = 2.05`、`maxSec = 4.65`、`cropCenterRatio = 0.27`，使 `0–56 帧` 精准覆盖「紧迫通话 → 抬手看表 → 锁定时间」完整动作，且 `App.tsx` 与 `ExportModal.tsx` 共用同一采样配置。
3. **重排弹幕 Y 轴避让区与视觉修瑕**：
   - 经逐帧网格检视与浏览器实机截屏核验，将 5 道 `52–54px` 弹幕重排至 `y = 128`（顶部暗化天空蒙版上方）、`y = 806 / 892 / 978`（深色西装胸前高对比区）及 `y = 1802`（主标题下方），完整让开人脸通话区（`190–720`）与抬腕看表区（`1030–1280`）。
   - 修复黄色波普顶标上 `⚡` 图标黄底撞色不可见的问题，替换为高对比黑色圆点 `● 今日盘前第一信号`。
4. **保持 2.6 秒节奏锚点不变**：维持 `0–77 帧（2.60s）` 与总长 `1188 帧（39.60s）`、`f=64..74` 光刃清屏闭幕及第 02 段全部核对数据与停留时长。
