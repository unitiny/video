# 对话 03：整合首屏碎片片段、融入全球市场概况并重构独立多元动效

## 用户原话（第 03 轮）

> 开头 3 个片段播放太快了，而且内容太杂了。按以下要求进行修改：
>
> 1. 内容合并：将 3 个片段全都合并成一个片段（即一张图片），并把全球主要指数等全球市场概况加进去突出显示，将图片与主要市场情况合并在一起。
> 2. 动画效果：要有动态效果。不是“呼吸”效果，也不是“逐帧进入”的效果，而是多样化的动态效果，即各个元素独立运行、独立发挥。
> 3. 播放速度：合并后的片段播放速度要慢一点，留出阅读的时间。

---

## 思考过程与设计判断

1. **收敛节奏与去碎片化**：连续 3 个短碎镜头切换过快导致观众来不及看清主线，将该阶段合并为一个结构统一、信息聚焦的开场总览段，并适当拉长阅读停留。
2. **摒弃廉价统一动效（反模板化）**：
   - 不能全员套用整体 `sin()` 呼吸缩放，也不能简单机械地 `fade-in` 逐帧堆叠。
   - **独立生命周期机制**：背景视觉慢推进、梗文字物理砸落与扫光、全球主要指数标签独立横向滑入或脉冲刷新、底部提醒条独立推进——每个视觉层拥有各自的时间函数与运动曲线，互不依赖却形成节奏合唱。

## 对应执行动作

- 将开篇多碎段收敛为统一的开屏整合结构，拉长单幕展示窗口。
- 为背景、主标题、指数信息层拆解各自独立的缓动与物理运动曲线（`easeOutBack`、`easeOutCubic`、扫光与粒子各行其道）。
