## 思考过程与设计判断

1. **功能解耦（01 情绪吸睛 vs 02 市场拆解）**：把原先挤在一起的梗图与指数完全分离为两个独立镜头：
   - **Shot 01**：纯粹全屏真人实拍动态视频 + 梗标题，并在末尾完成元素逐个退场清屏，留出干干净净的过渡，不带任何指数图表抢戏。
   - **Shot 02**：完全围绕「全球按开盘时序接力」铺排，行与行自上而下依次推进：
     - 第 1 排（各占半幅）：`纳斯达克 IXIC` + `费城半导体 SOX`，保留日 K 与补全的分时图；下方放醒目高亮大标题 + 联网核查的消息面原因（Anthropic 虹吸流动性 / 鹰派预期），打字机逐字打出，并**强制作出 1.0 秒（30 帧）阅读停顿**后再出下一排。
     - 第 2 排（各占半幅）：`韩国 KOSPI` + `日经 225`，下方打字机归因受隔夜美股半导体冲击低开走低。
     - 第 3 排（各占半幅）：筛选显着异动大宗商品（如黄金、波动明显的期货，自动过滤平盘资产）及简短归因。
     - 第 4 排（通栏重点）：`富时中国 A50` 单独大卡展示。
2. **极简信息原则**：卡片内只保留「标题 + 实时涨跌幅 + 日 K + 全天完整分时」，砍掉「跌了多少点」「韧性苗」等干扰视线的小标签。
