# QuantReel Studio — 每日盘前财经短视频通用生产工作流（SOP）

本工作流沉淀自 [`docs/1120_v2_memory_and_docs/`](1120_v2_memory_and_docs) 的 13 轮精修实践，已通过通用引擎 `src/video/engine/`、多源实盘抓取脚本与自动质检脚本彻底工程化。  
目标：**每日盘前（08:00 前）输入当日收集的热点事件与观点，30 分钟内产出 1080×1920 · 30fps · 112 BPM 立体声成片。**

---

## 一、不可突破的 6 条创作铁律（已内置进 `validate-episode.ts`）

1. **前 2.6 秒极速留存（`78 帧`）**：
   - 首屏总时长严格控制在 `2.0s–3.0s`（最佳 `2.60s / 78 帧`），包含入场、齐览与光刃清屏转场。
   - **真人实拍优先、零感叹夸张、零全屏抖动**：优先从 `assets/hooks/manifest.json` 选用紧迫商务/交易质感实拍视频，禁止整屏相机晃动。
   - **5 道大字精炼弹幕**：`52–54px`、单条 ≤ 20 字（硬上限 ≤ 24 去 emoji 字符）、必须严格避开钩子素材标注的 `forbiddenZones`（人脸区、手腕看表区）。
2. **实盘数据零造假（多源交叉核验）**：
   - 全球主要指数与商品必须使用真实交易所 5 日日K + 48 点全天分时，**严禁手绘或臆造曲线**。
   - 必须校验：① 开盘跳空方向与实盘一致；② 曲线末点与 `changePct` 误差 ≤ `0.35%` 且同号；③ 期货换月跳空必须经新浪连续合约复核；④ 平盘大宗商品（`|changePct| < 2.5%`）自动过滤；⑤ 成交量经 `P95` 截断防尾盘集合竞价压扁日内量能。
3. **全球开盘时序与阅读呼吸感**：
   - 镜 02 固定按全球开盘时序自上而下 4 层推进：**隔夜美股（双卡）→ 早盘亚太（双卡）→ 显著异动大宗（双卡，平盘过滤）→ 富时中国 A50（通栏压轴）**。
   - 卡片极简化：**仅留标题 + 涨跌幅 + 5日日K + 全天分时**，禁止塞入点数差、“韧性苗”等微小干扰标签。
   - **强制阅读停顿**：美股打字机结束后停 ≥ `30 帧（1.0s）`；A50 展毕后留 ≥ `55 帧（1.83s）` 停留窗。
4. **事件镜头模块化与跳色节奏**：
   - 每个当日核心事件分配 `5.0s（150 帧）`，根据事件性质从 3 大标准视觉模板中选型（可自由组合 2~4 个事件，不锁死 3 个）：
     - `event_flow_funnel`（**Vox 暖白方格纸 + 无交叉贝塞尔漏斗**）：适合资金虹吸、产业链传导、宏观流动性抽血/流入类事件。
     - `event_dual_spotlight`（**工程蓝图 Focus-and-Dim 双焦聚光 + 实体红章砸落**）：适合真景气 vs 蹭概念、业绩兑现 vs 未量产公告风险、多空硬核对照类事件。
     - `event_timeline`（**真实人物/主题视觉 + 三节点悬浮时间轴**）：适合政策/发布会/产业催化密集节点梳理（涉及真实人物如马斯克等必须基于真人肖像参照生成）。
5. **严守客观纪律边界，杜绝主观喊单**：
   - 禁止“唯独抗跌”“必涨”“必跌”“闭眼买”“满仓梭哈”“强烈推荐买入”等主观溢美或违规喊单词。
   - 期货（如 A50）只陈述客观盘中形态（如“早盘急探 -2.30% 后震荡回升收 -1.35%”），不混淆期货与现货。
6. **双情景终局收官（`8.0s / 240 帧`）**：
   - 上半屏「结构支撑 3 条 vs 承压制约 3 条」红青对仗；下半屏以 **10:00 前 30 分钟量能观察窗** 为分水岭，绘制「情景 A（承接修复）」与「情景 B（缩量回落）」两条分叉路径，只给观察应对预案，不做单边涨跌断言。

## 二、每日 5 步标准生产 SOP

### Step 1：收集当日输入（你发给 AI）
把你早盘收集的以下信息直接丢给 AI（零散要点即可）：
- 2~4 个当日最核心的热点事件/公告/隔夜消息面
- 你关注的主线板块、潜在踩雷/澄清风险标的
- 当日盘前氛围判断（偏防守 / 偏分歧 / 偏进攻）

### Step 2：一键抓取 & 多源核验全球实盘数据
```bash
bun scripts/fetch-market-data.ts --date YYYY-MM-DD
```
产出两个文件：
- `episodes/YYYY-MM-DD/market_verified.json`：可直接灌入渲染引擎的 5 日日K + 48 点分时 + P95 量能结构化数据
- `episodes/YYYY-MM-DD/market_audit.md`：**人工核验单**（列出数据源、开盘跳空%、期货换月交叉比对告警、已过滤的平盘大宗）

> **人工/AI 核查点**：先看 `market_audit.md` 是否有换月警告或某市场休市提示，确认无误再进入下一步。

### Step 3：生成当日分镜脚手架 & 填写事件脚本
```bash
bun scripts/create-episode.ts --date YYYY-MM-DD --market episodes/YYYY-MM-DD/market_verified.json --hook watch_45749
```
然后由 AI 根据你的热点事件，编辑 `episodes/YYYY-MM-DD/episode.json`：
1. 选定 01 幕波普标题（如 `今天 [很] 关键!!` / `盘前 [大] 分歧!!`）与 5 道 ≤18 字核心行情弹幕。
2. 补齐 02 幕美股/亚太/大宗的当日联网核实归因（每条 1~2 句，客观精炼）及 A50 分时形态描述。
3. 为 2~4 个热点事件选择最贴合的模板（`event_flow_funnel` / `event_dual_spotlight` / `event_timeline`），配置配图至 `episodes/YYYY-MM-DD/assets/`（可在 `episode.json` 中用 `/episodes/YYYY-MM-DD/assets/xxx.jpg` 引用）。
4. 编写 06 幕「支撑 vs 承压 3+3 条」与「10:00 双情景分叉数值」和保守结语。

### Step 4：运行自动质检红线
```bash
bun scripts/validate-episode.ts episodes/YYYY-MM-DD/episode.json
```
必须 **0 Error** 通过。质检会自动拦截：
- 首屏超时（非 2.0s–3.0s）或弹幕遮挡人脸/看表禁遮区
- 曲线末端与涨跌幅方向/数值不一致、日K OHLC 倒挂
- 美股停顿 < 1.0s 或 A50 停留 < 1.67s
- 任何主观喊单/违规词（如“唯独抗跌”“必涨”“闭眼买”）
- 引用的本地图片/视频路径缺失

### Step 5：工作台逐帧抽检 & 一键导出 MP4
1. 打开 QuantReel Studio（`bun run dev` → `http://127.0.0.1:3000`）。
2. 在「每日剧集」下拉框点「刷新列表」，选中 `YYYY-MM-DD`，逐幕抽检关键帧画面（确认无文字折行溢出、无遮挡）并试听 112 BPM 动态对齐音效。
3. 点击右上角 **「导出 MP4 成品」** → 自动走本机 FFmpeg（`libx264 crf 18 + AAC 192k`，跨平台自动识别 PATH 中的 `ffmpeg`；离线环境自动兜底浏览器 WebCodecs），直接下载 `YYYY-MM-DD_morning_intel_final.mp4`。

## 三、扩充复用素材库的方法

### 新增真人开场钩子视频
1. 将无版权真人实拍 MP4 放入 `assets/hooks/`（并提取 1 张海报图）。
2. 在 [`assets/hooks/manifest.json`](../assets/hooks/manifest.json) 的 `hooks` 数组中追加一条配置，标明：
   - `moods`（如 `["urgent", "bullish", "calm"]`）
   - `sample`（动作高潮窗口 `minSec` / `maxSec` 与竖屏裁切重心 `cropCenterRatio`）
   - `forbiddenZones`（人脸区、关键动作区 Y 坐标范围）
   - `danmakuSlots`（5 条避让禁遮区的安全弹幕 Y 轨道）
3. 下次执行 `create-episode.ts --hook <你的hookId>` 即可一键复用。
